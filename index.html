Backup & restore

Your questions are stored in this browser on this device. Export backups regularly; clearing Safari website data may erase the local database.

Backups may contain question text, answers, explanations and screenshot images. Keep them private. AI answers are never marked verified automatically.

AI extraction endpoint (optional)

The core vault works without AI. To enable model-assisted extraction later, configure a private backend endpoint. Do not paste an NVIDIA or Gemini API key into this page or a public repository.

This is your own Worker access token, not your Gemini/NVIDIA API key. It is stored only in this browser’s local settings.

The provider API key stays on the Worker. The app access token is stored locally in this browser and is excluded from exported backups. The backend must accept POST JSON and return structured question data. See worker-example.js in the project bundle.

Data & privacy

No account or cloud sync is built into this prototype. The screenshot and question database stays in this browser unless you export it or deliberately send an image to an AI endpoint.
